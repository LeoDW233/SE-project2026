Software Purpose: 1. What development process does this software use? Our game uses an agile software development process.

2. Why choose this process? Because we want to ensure the best efficiency for this software development project, simplifying the process and reducing costs (e.g., time). Agile software development allows us to respond quickly to changes in requirements. For example, users might want the game to adopt a new style or establish a connection with a certain brand. In this case, we can modify and add code to meet these new requirements in the shortest possible time. Our focus is on dynamically managing requirement changes and user feedback and integrating them into the software in a timely manner.

3. Potential uses of the software. Target market: People with fragmented free time. (Our game doesn't require much time, allowing people with fragmented free time to enjoy entertainment.)

Development Process: Requirements Phase: Entering the visual product output phase, discussing and providing the simplest and closest "product prototype" to the final product. Based on the requirements and project requirements, each student clarified the specific time nodes for each phase and finally carried out "project task decomposition" according to the development plan, completing the project division of labor.

Design Phase: Students provide interface annotations, and finally, based on the main interface, output the "requirements specification" in Unity. Development Phase: Students begin coding. While most of the time is spent writing code, functional reviews will be conducted after coding is complete.

Testing Phase: Students modify their code based on test results, submit it for testing, and complete the final version after passing the tests.

Schedule: April 5th: Conceptualize the development plan; April 10th: Briefly present the concept for the final product; April 11th-16th: Code completion; April 18th: Software testing.

Algorithm: Use the WASD keys and Space key to control the character's left and right movement and jumping. The game ends when the character steps on a red spike or falls into the void; the character wins when they land on a green platform.

Current Software Status: The game is written using Unity 2D and Visual Studio Code (C#).

Future Plans: More levels will be added to the game in the future.
